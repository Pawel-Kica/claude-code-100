# My guidelines

These win over taste.md and frontend-design.md when they conflict.

## Font

Always use the native system font (SF Pro on Mac). No web fonts, no Geist/Inter/serif picks.

```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", "Helvetica Neue", Arial, sans-serif;
-webkit-font-smoothing: antialiased;
```

## Don'ts

- cream or off-white backgrounds
- italic accent words in headings
- numbered "01 / 02 / 03" section labels
- monospace labels
- pill-shaped buttons
